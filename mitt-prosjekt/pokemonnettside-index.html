My 10 Favourite Pokemon!

Hello! My name is Nathalie and welcome to my website! Here I would like to show off 10 of my favourite Pokemon and talk a little bit about why I like them so much.


#1: Giratina

Class:

Renegade Pokemon

Type:

Ghost/Dragon

Description:

This is my favourite Legendary Pokemon! I remember first seeing this Pokemon in an art book and thought; "Whoa, that's a cool Pokemon!".

#2: Mimikyu

Class:

Disguise Pokemon

Type:

Ghost/Fairy

Description:

The lore behind it is so sad. :( The Pokemon disguises itself as Pikachu (who is popular) so it can be loved. I liked the Pokemon so much I made a DND character based on it.

#3: Primarina

Class:

Soloist Pokemon

Type:

Water/Fairy

Description:

It's such a pretty Pokemon! Before Pokemon Sun/Moon released, I saw a leaked image of Primarina and I hoped so badly that it wasn't fake. I was so happy when it turned out to be real!

#4: Meowscarada

Class:

Magician Pokemon

Type:

Grass/Dark

Description:

I really like the magician theme it got going on. The design has a lot of personality. Plus I'm a cat person. :3

#5: Nidoking

Class:

Drill Pokemon

Type:

Poison/Ground

Description:

I always used one whenever I replayed Pokemon Leafgreen. So I ended up growing pretty fond of this dude.

#6: Scolipede

Class:

Megapede Pokemon

Type:

Bug/Poison

Description:

I've always loved Bug types and Scolipede is my favourite one. I mean LOOK AT IT - it's a giant centipede horse that can roll around like a wheel. That's SO SICK!

#7: Empoleon

Class:

Emperor Pokemon

Type:

Water/Steel

Description:

Pokemon Diamond was my very first Pokemon game. I liked all of the starters, so I decided to randomly pick mine. I ended up choosing Empoleon.

#8: Alolan! Raichu

Class:

Mouse Pokemon

Type:

Electric/Psychic

Description:

In Pokemon Sun/Moon Raichu got a regional form! I've always liked Raichu more than Pikachu and this is my fav version of them. It's just so cute!

#9: Hydrapple

Class:

Apple Hydra Pokemon

Type:

Grass/Dragon

Description:

Sometimes I don't want a Pokemon that is cute or cool. Sometimes I want something really silly, like a 5-headed dragon hiding in a bigass apple.

#10: Ceruledge

Class:

Fire Blades Pokemon

Type:

Fire/Ghost

Description:

I LOVE THIS GUY'S COLOURS! The sword arms and knight theme is also very cool.
