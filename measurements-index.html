CSS Measurements

This page shows common CSS Units of measurement. Resize the browser to compare.

Measurements

Pixels (px)

A pixel is an absolute unit. Its size does not depend on the parent element or viewport.

width: 200px

Percent (%)

A percentage is based on the size of the parent element.

width: 50%
width: 50%
width: 50%

em (em quadrat)

em is relative to font size. For font-size it is based on the parent's font-size. For padding and margin, it is based on the element's own font-size. NOT TO BE CONFUSED WITH THE EM/EMPHASIS TAG!!

font-size: 1em

font-size: 2em

rem (root em)

rem is based on the root (html) font-size. It is commonly used for consistent font sizes and spacing. Considered best practice for text. rem = X times the html's font-size.

font-size: 10rem

ch (character)

ch is approximately the width of the "0" character. It is useful for controlling the readable length of text. 60-70 ch is usually considered the sweet spot.

vw (viewport width)

vw is based on the browser width. 1 vw is 1% of the viewport width. Unlike %, it is NOT based on the parent.

width: 50vw

vh (viewport height)

vh is based on the browser height. 1vh is 1% of the viewport height. We can set the height of a container to 100vh to take up the entire screen, no matter waht size monitor/viewport the user has. Good for hero section.

height: 30vh
