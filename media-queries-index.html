CSS Media Query

We can use CSS Media Queries to change our CSS when we resize the browser, rotate a device, enable Dark/Light Mode, turn on Reduce Motion, or open Print Preview.

Screen Size

Uses the width of the browser window to change styles. Commonly used for responsive layouts across desktop, tablet and mobile devices.

Orientation

Detects whether the available space is taller or wider. Useful when adapting layouts for devices being rotated.

Dark Mode

Detects whether the user prefers a dark colour theme. Websites can adjust colours automatically.

Reduced Motion

Detects when a user has requested fewer animations. This improves accessibility for people who experience discomfort from motion effects.

Print

Applies styles when the page is printed. Useful for removing unnecessary elements and creating print-friendly pages.
