Validation, Accessiblity and SEO

In real projects, we must check that our code is correct, accessible and understandable.

HTML Validation

HTML Validation checks if your code follows the correct rules.

Error can cause sites to break or behave unexpectedly.

Common mistakes:

  • Missing closing tags
  • Incorrect nesting (div inside p).
  • Missing alt attributes on images.

W3C Validator

The W3C Validator checks if your HTML is correct.

Go to: https://validator.w3.org/

Accessiblity Checking

Accessibility means your entire website works for everyone, including those who use screen readers.

In many countries, including Norway, accessbility is required by law.

Accessiblity Tools

Useful tools:

  • Lighthouse (built into Chrome devtools)
  • WAVE (wave.webaim.org)
  • axe DevTools (browser extension)

What these tools check:

  • Missing alt atribute on images.
  • Bad color contrast.
  • Missing labels on inputs.
  • Incorrect HTML structure.

Important SEO Elements

  • Title - shows in browser tab
  • Favicon - shows in browser tab
  • Meta Description - short page summary
  • Headings - organize content
  • Alt Text - helps describe images

Colour Contrast
