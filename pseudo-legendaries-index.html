CSS Pseudo Classes and Pseudo Elements

Pseudo-classes and pseudo-elements allow CSS to style elements based on their state or style specific parts of an element.

Pseudo Classes

A pseudo-class uses a single colon (:). It styles an element when it is in a particular state.

:hover

Applies styles when the mouse pointer is over an element. Commonly used for buttons and links.

:focus

Applies styles when an element is selected. Important for keyboard users and accessibility.

:active

Applies styles while an element is being clicked.

:first-child and :last-child

Selects elements based on their position inside a parent.
